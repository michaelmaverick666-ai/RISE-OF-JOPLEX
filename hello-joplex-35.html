                  🧬 CRISPR

                  CRISPR stands for Clustered Regularly Interspaced Short Palindromic Repeats. It is a family of biological systems that can be used to target specific DNA sequences.

                  🔬 Key components

                  Cas9: an enzyme that can cut DNA.

                  Guide RNA: helps direct Cas9 toward a particular DNA sequence.

                  DNA: the molecule that stores genetic information.

                  🧠 Simple example

                  Think of DNA like a huge book. The guide RNA helps find the target, while Cas9 acts like molecular scissors.

                  🌍 Why it matters

                  CRISPR is important in biological research, medicine, agriculture, and the study of genetic diseases.

                  Joplex Knowledge Base: Biotechnology. Educational summary, not medical advice. Reviewed Oct 2026. Verify with a qualified source.

                                  How it works
                                  
        
                                  Neurons, weights and biases
                                  A neuron multiplies each input by a weight, adds them up, adds a bias, then passes the total through an activation function: a = f(w1·x1 + w2·x2 + b). Weights say how much each input matters. The bias moves the threshold at which the neuron switches on.
                                  
        
                                  Layers and depth
                                  A layer is a group of neurons that all look at the same inputs. The input layer is your data. Hidden layers build new features from earlier ones. The output layer gives the answer. A single straight-line model cannot separate XOR, but one hidden layer can, because the hidden neurons carve out new shapes that the output combines.
                                  
        
                                  Training and learning
                                  Each epoch: predict, measure the loss (how wrong), then use backpropagation to work out how each weight should change, and nudge them with the Adam optimiser. The loss curve should fall. The boundary picture shows what the network currently believes.
                                  
        
                                  Deep learning, and what Joplex does not do
                                  Deep learning means many layers, usually with huge data and GPUs. Joplex trains small networks only (up to 3 hidden layers). Convolutional networks, transformers and GPU training are not available here. They need a Python framework, which is NOT CONNECTED.
